## Procedimento

1. Extrair/copiar a pasta `assets/images/` deste ZIP para a raiz do projeto, mantendo os nomes.
2. Reutilizar a primeira imagem existente no repositório para cada produto.
3. Usar as duas imagens complementares `-02.webp` e `-03.webp` como fotos 2 e 3 da galeria desse produto.
4. Não inventar nomes `-04.webp` ou `-05.webp`: esses arquivos não foram entregues.
5. Atualizar `assets/IMAGES.md` sem remover os créditos Pexels já registrados para as imagens originais.
